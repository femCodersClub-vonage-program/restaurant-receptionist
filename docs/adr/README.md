# Architecture decision records

Architecture decision records (ADRs) preserve significant technical decisions, their context, and their consequences. They do not replace the [business rules](../business-rules.md).

Each ADR includes its status, context, decision, alternatives considered, and consequences. A later ADR may supersede an earlier one when the project changes direction.

Use the [ADR template](_template.md) for new records.
