# Code of Conduct

Restaurant Receptionist is a FemCoders Club project. We expect inclusive, respectful, and constructive collaboration in code reviews, GitHub discussions, and Slack conversations. Harassment, discrimination, or hostile conduct is not acceptable.

The official [FemCoders Club Code of Conduct](https://www.femcodersclub.com/codigo-de-conducta) and its reporting procedure take precedence over this summary.

Do not report concerns or share personal information in public GitHub issues, pull requests, or Slack channels.
